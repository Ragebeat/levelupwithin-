Privacy Policy

Last updated: June 3, 2026

This Privacy Policy describes how LevelUpWithin ("we", "us", or "our") handles information in connection with our Pinterest integration tool.

1. Overview

LevelUpWithin is a personal content automation tool used solely to publish self-improvement content to our own Pinterest account (@levelupwithin). It is not a public-facing application and has no end users other than its owner.

2. Data We Collect

We do not collect, store, or process personal data from any third parties. The tool operates entirely on a private local machine and interacts only with our own Pinterest account via the official Pinterest API.

3. Pinterest API Usage

We use the Pinterest API solely to:

  • Publish pins to our own boards
  • Read our own board list

No data retrieved from the Pinterest API is stored, shared, or used for any purpose other than publishing content to our own account.

4. Third-Party Services

Image generation uses the HuggingFace Inference API. No personal user data is transmitted to HuggingFace — only text prompts for image generation.

5. Data Sharing

We do not sell, trade, or share any data with third parties.

6. Data Retention

No user data is retained. Temporarily generated image files are deleted immediately after publishing.

7. Children's Privacy

This tool is not directed at children under 13 and does not collect any information from children.

8. Changes to This Policy

We may update this Privacy Policy occasionally. Changes will be reflected by updating the "Last updated" date above.

9. Contact

For any questions regarding this Privacy Policy, please contact us via our Telegram channel: @levelupwithin.
